# דיווח נוכחות לעובדים ממלאי מקום

אפליקציית ווב מלאה (Next.js + PostgreSQL) לניהול דיווחי נוכחות: חשבת שכר מנהלת עובדים, מחלקות, ורכזים; רכזים מתחברים עם שם משתמש וסיסמה אישיים ומדווחים שעות.

## מה יש בפנים
- התחברות מוגנת (שם משתמש + סיסמה) לחשבת השכר ולכל רכז בנפרד.
- ניהול עובדים, מחלקות (עם מספר מחלקה ותעריף), ורכזים.
- פתיחת/סגירת חודש לדיווח.
- דיווח שעות לפי עובד + מחלקה, כולל "דיווח הפרשים" לחודשים סגורים.
- זכאות נסיעות פעם בחודש לכל עובד.
- דוח אקסל מרוכז (שתי לשוניות: נוכחות + הפרשים) ודוחות PDF (לכל עובד, ולכל מחלקה בנפרד — דף לכל עובד, לפי סדר א-ב).

## שלב 1: הקמת בסיס נתונים (Supabase)
1. הירשמו ב-[supabase.com](https://supabase.com) וצרו פרויקט חדש (חינמי).
2. בתפריט Project Settings → Database, העתיקו את שני מחרוזות ההתחברות:
   - **Connection pooling** (פורט 6543) → זה יהיה `DATABASE_URL`
   - **Direct connection** (פורט 5432) → זה יהיה `DIRECT_URL`

## שלב 2: הגדרת משתני סביבה
1. העתיקו את `.env.example` לקובץ בשם `.env`.
2. מלאו את `DATABASE_URL` ו-`DIRECT_URL` מהשלב הקודם.
3. הגדירו `SESSION_SECRET` — כל מחרוזת אקראית וארוכה (אפשר לייצר ב-[randomkeygen.com](https://randomkeygen.com)).
4. הגדירו `ADMIN_USERNAME` / `ADMIN_PASSWORD` / `ADMIN_NAME` — פרטי ההתחברות הראשוניים של חשבת השכר.

## שלב 3: התקנה מקומית (לבדיקה לפני העלאה)
```bash
npm install
npx prisma migrate deploy   # יוצר את הטבלאות בבסיס הנתונים
npm run seed                # יוצר את משתמש חשבת השכר הראשוני
npm run dev                 # מריץ מקומית על http://localhost:3000
```
התחברו עם ה-ADMIN_USERNAME / ADMIN_PASSWORD שהגדרתם.

## שלב 4: העלאה לאירוח (מומלץ: Render)
1. העלו את הפרויקט לריפוזיטורי ב-GitHub.
2. ב-[render.com](https://render.com) צרו **Web Service** חדש, וחברו אותו לריפוזיטורי.
3. הגדרות בנייה:
   - Build Command: `npm install && npx prisma migrate deploy`
   - Start Command: `npm start`
4. הוסיפו את כל משתני הסביבה מה-`.env` שלכם בהגדרות ה-Environment של Render.
5. אחרי הפריסה הראשונה, הריצו פעם אחת `npm run seed` (מ-Render Shell, או מקומית מול אותו `DATABASE_URL`) כדי ליצור את משתמש חשבת השכר.
6. גשו לכתובת שנתן Render, והתחברו.

## הערות חשובות
- **PDF**: נוצר בשרת עצמו (לא בדפדפן), כך שאין את המגבלות שהיו בסביבת האב-טיפוס. אם ה-PDF נכשל אחרי הפריסה, כנראה שהאירוח שבחרתם לא תומך בהרצת Chromium — פנו אליי ואבחר עבורכם ספרייה חלופית (למשל pdf-lib) שלא דורשת דפדפן.
- **סיסמת האדמין**: לאחר ההתקנה הראשונה מומלץ להחליף את סיסמת חשבת השכר. אין כרגע מסך "שינוי סיסמה" בממשק — אפשר להריץ שוב `npm run seed` עם `ADMIN_USERNAME` קיים (הוא ידלג, כי המשתמש כבר קיים) — כדי לשנות סיסמה בפועל, יש למחוק את המשתמש הקיים מבסיס הנתונים (או לבקש ממני להוסיף מסך "שינוי סיסמה").
- **רכזים**: חשבת השכר יוצרת להם שם משתמש וסיסמה בטאב "רכזים". אין כרגע מסך "שכחתי סיסמה" — אם רכז שוכח סיסמה, חשבת השכר יכולה למחוק ולהוסיף אותו מחדש.
